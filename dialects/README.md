# Arabic dialect guidance

Load the guide for the narration's requested dialect before drafting or adapting
its script. These guides cover Arabic grammar, vocabulary, forms of address
and examples for 23 varieties.
Read this index and the relevant file; there is no need to load the whole collection.

## Using a guide

1. Resolve the requested variety using the index below and the brief or config's
   `dialect`. For this starter's examples, use `saudi-najdi`, `eg-cairene` or `ae`.
   If a country-level request leaves the regional variety unclear, clarify when
   it matters to the brief; otherwise state your chosen variety.
2. Read that file before writing the scene scripts. Use its grammar and ordinary
   phrasing naturally; keep the dialect consistent across scenes. For MSA, use the
   MSA guide's formal register. Apply the writing guidance to narration; keep
   your replies to the user in their preferred language.
3. Preserve a supplied or approved script unless adaptation is requested. When
   drafting, keep names, offers, numbers and meaning intact. Select forms of
   address and expressions for the actual audience and context. Conversational,
   telephone, religious and social examples are optional context, not required
   lines to insert into an advertisement or explainer. Choose the level of
   formality and any foreign-language wording to fit the brief and audience.
4. Find an actual ready voice through the current voice catalog or MCP tools.
   These filenames are dialect codes, not voice IDs or proof of current voice
   availability. Writing dialect copy and selecting a suitable voice are separate
   steps. Keep one voice across the scenes unless the brief calls for more.
5. Put only the finished narration in each scene's `script` or the TTS text input.
   Keep reference instructions, pronunciation explanations and examples out of
   the spoken text. Titles and captions remain separate display copy. Review
   names, numbers and dialect consistency, then listen to the generated recording
   before accepting it; written guidance does not certify pronunciation.

## Guides

for it. A broader or nearby guide can inform a draft only with its
scope stated; it is not an equivalent regional variety. Confirm actual filter
